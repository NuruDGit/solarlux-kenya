## 3. Payload CMS Collections

Minimum viable schema. Expand as needed.

### Pages
Flexible page builder for marketing pages if marketing wants to edit without dev involvement.
- `title`, `slug`, `hero` (group), `blocks` (array of content blocks), `seo` (group)

### Products
- `name` (text)
- `slug` (text, unique)
- `category` (relationship → ProductCategories)
- `brand` (relationship → Brands)
- `shortDescription` (textarea)
- `description` (Lexical richText)
- `specifications` (array of { label, value })
- `keyFeatures` (array of text)
- `priceFrom` (number, optional)
- `priceCurrency` (select: KES, USD)
- `priceNote` (text — "Starting from" / "Contact for pricing")
- `warranty` (text)
- `images` (array → Media)
- `datasheet` (upload → Media, PDF)
- `isFeatured` (checkbox)
- `isInStock` (checkbox)
- `applications` (select multi: residential, commercial, hospitality, agricultural)
- `seo` (group: title, description, ogImage)

### ProductCategories
- `name`, `slug`, `description`, `heroImage`, `icon` (Lucide name)

### Projects (Case Studies)
- `title`, `slug`, `location` (text — e.g., "Watamu, Kilifi")
- `client` (text, optional — may be anonymised)
- `sector` (select: residential / commercial / hospitality / agricultural)
- `systemSize` (text — e.g., "10kVA 48V 8kW")
- `components` (array of text or relationship → Products)
- `summary` (textarea)
- `challenge`, `solution`, `outcome` (Lexical richText)
- `images` (array → Media)
- `completedDate` (date)
- `featured` (checkbox)
- `testimonial` (relationship → Testimonials, optional)

### Testimonials
- `quote` (textarea)
- `authorName`, `authorRole` (text)
- `authorImage` (upload → Media)
- `project` (relationship → Projects, optional)
- `rating` (number 1–5, optional)
- `featured` (checkbox)

### BlogPosts
- `title`, `slug`, `excerpt`, `content` (Lexical)
- `author` (relationship → TeamMembers)
- `category` (select: guides / news / case-studies / tips)
- `tags` (array of text)
- `heroImage` (upload → Media)
- `publishedDate` (date)
- `readTime` (auto-calc or manual)
- `seo` (group)

### TeamMembers
- `name`, `role`, `bio` (richText)
- `photo` (upload → Media)
- `linkedin` (url, optional)
- `order` (number — display order)
- `isFounder` (checkbox)

### Brands (partner manufacturers)
- `name`, `logo` (upload → Media), `website` (url)

### Media
- Standard Payload Media collection
- Image sizes: `thumbnail` (300w), `card` (600w), `feature` (1200w), `hero` (1920w)
- Alt text required on every upload

### Globals

**SiteSettings**
- `phonePrimary`, `phoneSecondary`, `email`, `emailAlt`
- `addressLine1`, `addressLine2`, `city`, `country`
- `openingHours` (text)
- `whatsappNumber`
- `socialLinks` (array)
- `yearsInBusiness` (number) — used in "8+ years" stats

**Header**
- `navItems` (array of { label, href, children? })
- `ctaLabel`, `ctaHref`

**Footer**
- `columns` (array of { title, links })
- `legalText`
- `trustBar` (array of { icon, label })

## 6. First Sprint — Build Order

1. **Foundation** — install deps, set up Tailwind, drop in `globals.css` tokens, verify fonts load
2. **Layout shell** — root layout, header, footer, mobile menu, WhatsApp FAB
3. **Shadcn primitives** — button, input, card, dialog, sheet, accordion
4. **Motion primitives** — `FadeIn`, `SlideUp`, `Stagger` components
5. **Homepage** — hero, value props, featured products, stats bar, CTA
6. **About** — use PDF content
7. **Services overview + sub-pages**
8. **Solutions pages**
9. **Products** — category pages + detail pages (static data first, then Payload)
10. **Quote page** — primary conversion
11. **Projects gallery**
12. **Contact**
13. **Payload CMS** — wire up collections, migrate static content
14. **Blog / Resources**
15. **SEO, sitemap, robots, structured data**
16. **Performance audit, Lighthouse pass**
17. **Deploy**
